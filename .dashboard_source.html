Rules

One rule per row, for pilots and non-pilots alike. Applies to: All, or Role / Cat Status / Status / Callsigns with the values in Who (comma separated). Counts: Any flight, a Mission type from the Activities tab (e.g. MSN), or Flight codes (e.g. NVG-2.0, MSN-3.0). At least: blank = 1; a 2xFLT code counts as 2.

Flight codes: the flights programme

Add crew in the next empty row: regular crew at the top, SANS and NSmen in the purple section (they always show at the bottom of the planner). Cat Status sets the colour of the name: CAT A black, CAT B green, CAT C yellow, CAT D red, TRAINEE magenta. To remove someone, set Status to Inactive. Don't clear a person's row to reuse it for someone else: the month plans are tied to the row, so their old plan would carry over to the new person.

Its formulas, colours and dropdowns stay as they are, so the file keeps working in Excel.

Nothing is sent anywhere. Everything runs in this browser page, so it works on the intranet with no internet. Close the file in Excel before saving to it.
